# BISMART TRADERS — prototype

This is a responsive front-end prototype for a multi-market trading platform.

## Included
- Overview dashboard and sample portfolio
- Forex, crypto, stocks, gold and commodities market lists
- Simulated buy/sell trades
- Demo wallet with simulated deposit and withdrawal records
- Transaction history
- Demo / Live mode selector (Live mode is intentionally not connected)

## Run
Open `index.html` in a modern browser, or deploy the folder as a static website (for example, GitHub Pages).

## Important production requirements
This prototype is not a broker, exchange, payment processor, or financial service. Prices and positions are sample data. Demo deposits and withdrawals are local browser interactions and do not move money. It has no authentication, backend, database, custody, payment API, or real order execution.

Before any live-money launch, obtain the required licences for each target jurisdiction and engage a qualified compliance provider. Integrate a regulated broker/exchange for order execution; use a server-side database and authentication; implement KYC/AML, sanctions screening, fraud controls, audit logs, encryption, secure secrets management, and withdrawal approvals. Connect M-Pesa, bank transfer, card processing, and USDT only through appropriately licensed payment/custody providers. Never collect or store card numbers, wallet seed phrases, or private keys in this static website.

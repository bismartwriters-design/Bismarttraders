# BISMARTTRADERS website demo

Open `index.html` in a browser, or upload `index.html`, `style.css`, and `script.js` to your GitHub Pages repository.

This version uses a black-and-gold design and includes signup/login, a responsive dashboard, sample portfolio data, market watch and sample positions.

**Important:** This is a front-end demo only. Prices and balances are fictional. It does not execute trades, accept deposits, or connect to a broker. Demo login details are stored in browser localStorage and are not secure. Use a secure authentication provider and backend before collecting real user data or offering financial services.
